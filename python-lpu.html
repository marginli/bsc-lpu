STEP 227 鄰域平滑與上四分位取熱點

from scipy import ndimage

def smooth27(v):
    """3x3x3 均值平滑（論文的 27 體素平均）。"""
    return ndimage.uniform_filter(v, size=3)

def hotspots(v, mask):
    """在 neuropil 遮罩內取上四分位，回傳熱點體素座標 Z。"""
    vals = v[mask]
    qu = np.percentile(vals, 75)          # five-number summary 的 Q3
    return np.argwhere(mask & (v >= qu))  # Z
待補：印出五數綜合當教學素材；示範改動分位數對結果的影響。

記憶體警告：pdist 對 N 個體素會產生 N(N−1)/2 個距離。熱點若有十萬個體素，光距離矩陣就要約 20 GB。實作前必須先估算，並準備替代方案（空間分塊、下採樣、或改用連通元件＋分水嶺）。
待討論：cut 怎麼定？可能的作法：(a) 用已知答案的 VLP 反推一個切割高度，(b) 掃一段 cut 值看群數的穩定平台。這一步是整個重現工作的成敗關鍵。
